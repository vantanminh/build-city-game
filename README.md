# Thành Phố Của Tôi (CityBuilder)

Game xây thành phố isometric cho iOS (SwiftUI + SpriteKit), mã nguồn mở, đồ hoạ vẽ hoàn toàn bằng code và không dùng thư viện bên thứ ba.

## Công nghệ
- **Swift 5** / iOS 16+ (iPhone & iPad)
- **SwiftUI** cho giao diện HUD và cài đặt
- **SpriteKit** cho bản đồ isometric 2.5D
- **CityCore** (Swift Package thuần Foundation) cho mô phỏng và luật chơi
- **XcodeGen + GitHub Actions** (`macos-15`) để kiểm thử và đóng gói `.ipa` unsigned
